# SandPlay

Настольный плеер для своей музыки. Окно на Qt 6 Widgets, звук читается потоком через miniaudio, теги читает и пишет TagLib, библиотека лежит в SQLite. Исполняемый файл называется `SandPlay`.

Сеть используется только для обложек. Сами записи программа не скачивает.

## Сборка

Нужны CMake 3.21 или новее, компилятор C++20, Qt 6 (модули Widgets, Sql и Network) и TagLib. miniaudio уже лежит в `third_party/miniaudio`.

На Windows TagLib удобно ставить через vcpkg (`vcpkg install taglib`), Qt — официальным установщиком. Сборка из каталога проекта, после окружения MSVC x64:

```bat
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.x/msvc2022_64"
cmake --build build --config Release
```

Готовый файл — `build/SandPlay.exe` (или `build/Release/SandPlay.exe`, если генератор многоконфигурационный). Рядом с ним CMake запускает `windeployqt`, чтобы подложить библиотеки Qt. Окно консоли при запуске не открывается.

На Linux CMake ищет TagLib через pkg-config, если пакета vcpkg нет:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/SandPlay
```

## Что умеет

Форматы файлов: WAV, FLAC и MP3. Файлы с расширением `.fla` читаются как FLAC.

Библиотека:

- «Добавить трек» берёт один или несколько файлов.
- «Импорт папки» добавляет треки из папки (без вложенных каталогов) и создаёт плейлист с именем этой папки.
- Импортированная папка остаётся под присмотром: новое имя файла сохраняет ту же строку в библиотеке, удалённый файл из неё пропадает, новый файл в этой папке добавляется сам. Если папки сейчас нет на диске, её треки не удаляются.
- В списке сначала видны 200 последних треков, дальше кнопка «Показать ещё».
- Поиск ищет по названию, исполнителю и альбому, в том числе внутри слова. Несколько слов должны найтись все.
- В плейлисте до 2000 треков. Порядок меняется перетаскиванием.

Воспроизведение:

- Файл читается с диска по ходу проигрывания, а не целиком в память.
- Двойной щелчок ставит в очередь текущий результат поиска или открытый плейлист и начинает с выбранного трека. Повторный щелчок по тому, что уже играет, ставит паузу.
- Есть перемешивание, повтор одного трека и повтор всей очереди, эквалайзер на десять полос.
- Пробел — пауза и продолжение. Ctrl и стрелки влево/вправо — предыдущий и следующий трек, вверх/вниз — громкость. Клавиши мультимедиа работают так же. В поле поиска эти клавиши печатают текст, а не управляют плеером.

Обложки:

- Сначала берётся картинка из файла, затем обложка другого трека того же альбома.
- Если локально пусто, плеер спрашивает Deezer, iTunes и MusicBrainz с Cover Art Archive. Сохраняется JPEG не больше 600×600.
- Свою картинку можно задать правым щелчком. «Найти обложку в сети» повторяет поиск, если прошлый ничего не дал.
- Форма рамки: скруглённая, квадрат или CD. У CD картинка крутится, пока трек играет. Блик и отверстие в центре стоят на месте.

Оформление:

- Внизу окна узкая панель. Щелчок по ней открывает вкладку плеера на всё окно: крупная обложка, подписи, перемотка, громкость и очередь справа.
- Логотип в левом верхнем углу основного окна открывает меню: «Редактировать плеер», цвет кнопок и полос, эквалайзер. Во вкладке этого логотипа нет.
- В редакторе элементы перетаскиваются. Правый щелчок по названию меняет размер шрифта названия, исполнителя и альбома. У обложки там же форма и рамка, у кнопки — своя картинка PNG, у пустого места — фон. На нижней панели можно спрятать кнопки предыдущего и следующего трека.

Библиотека, обложки и раскладка хранятся только на этом компьютере: на Windows это `%APPDATA%\local\music-player` (`library.db` и папка `covers`). В репозиторий они не входят.

## Структура

```
CMakeLists.txt
third_party/miniaudio/
src/
├── main.cpp
├── db/Database.*              SQLite: треки, плейлисты, оформление, настройки
├── audio/
│   ├── AudioEngine.*          miniaudio: поток, пауза, перемотка, эквалайзер
│   └── PlaybackQueue.*        очередь, shuffle, повтор
├── library/
│   ├── LibraryManager.*       теги, импорт, слежка за папками
│   ├── CoverCache.*           JPEG на диске
│   └── CoverFetcher.*         Deezer, iTunes, MusicBrainz
├── models/                    списки библиотеки, плейлистов и очереди
└── ui/                        окно, вкладка, холст оформления, кнопки и обложка
```
